# AGRI SHIELD — AI & Computer Vision Subsystem

This module contains deep learning models, computer vision inference pipelines, and spread intelligence predictors.

## Directory Structure
- `models/`: PyTorch model architecture definitions (Crop disease classifiers, anomaly detectors).
- `pipelines/`: Feature extraction and multi-spectral band processing pipelines.
- `weights/`: Trained neural network model weights and checkpoints (tracked in storage, excluded from git).
