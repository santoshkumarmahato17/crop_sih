# AGRI SHIELD — Geospatial & Operational Data Catalog

This directory manages local geospatial schemas, sample vector boundary datasets, and reference catalogs.

## Structure
- `geojson/`: Sample farm boundaries, monitoring zone polygons, and drone flight corridors.
- `rasters/`: Local cached raster tiles and sample band GeoTIFFs for testing.
- `schemas/`: JSON schemas for farm telemetry, drone logs, and weather feeds.
