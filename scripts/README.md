# AGRI SHIELD — System Automation & Operational Scripts

Helper scripts for local environment bootstrap, data loading, database migrations, and verification.

## Scripts
- `start.ps1`: Powershell script to orchestrate the Docker container ecosystem.
- `start.sh`: Bash script to orchestrate the Docker container ecosystem.
- `verify_foundation.py`: System diagnostic script verifying backend health, PostGIS compatibility, and frontend builds.
